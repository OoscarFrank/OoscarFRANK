### 🔧 What I'm working on

- 🐧 **Yocto images** for embedded Linux: automated installer, custom partitioning, Wi-Fi and Bluetooth driver integration
- 🔐 **Secure OTA updates** with RAUC, on a fleet of **80 devices** at customer sites
- 🛰️ **Fleet management** with qbee, plus firmware updates for Wi-Fi, Bluetooth and LoRa sensors
- 📊 **IoT data pipelines**: MQTT queues on RabbitMQ → SQL → Grafana dashboards, with Highbyte for plant machine data
